# E-commerce Inventory and Supply Chain Analysis

This project presents an interactive Supply Chain Analytics Dashboard developed using Power BI using the E-Commerce dataset. The dashboard focuses on analyzing logistics performance, delivery efficiency, revenue trends, order processing, and operational insights across different states and cities. The dashboard helps monitor supply chain activities and provides data-driven insights for improving delivery operations and business performance.

---

## Overview

The dashboard provides insights into:
- Supply chain operations
- Delivery performance
- Order fulfillment
- Revenue trends
- Inventory prioritization
- Geographic logistics analysis


---

## Tools & Technologies

- Power BI
- Excel
- Python

---

## Key Features

### Logistics & Delivery Analytics
- On-Time Delivery Analysis
- Late Delivery Monitoring
- Average Delivery Days
- Orders In Transit Tracking
- Delivery Volume by Day of Week

### Revenue & Order Analysis
- Revenue Trends
- Revenue Contribution by State
- Order Status Distribution
- Top Performing Regions

### Inventory Segmentation
- ABC Analysis based on revenue contribution
- XYZ Analysis based on demand variability

### Geographic Insights
- State-wise Performance Analysis
- Delivery Performance by Region
- Customer Distribution Analysis

---

## ABC Analysis

ABC Analysis was implemented to classify products based on their revenue contribution.

| Category | Description |
|---|---|
| A | High-value products contributing major revenue |
| B | Medium-value products with moderate contribution |
| C | Low-value products with smaller contribution |

This analysis helps prioritize inventory and operational focus.

---

## XYZ Analysis

XYZ Analysis was used to classify products based on demand variability.

| Category | Description |
|---|---|
| X | Stable demand products |
| Y | Moderate demand variability |
| Z | Highly variable demand products |

This analysis supports demand planning and supply chain optimization.

## Key Insights

- Most orders were delivered successfully and on time
- Delivery volume was higher during weekdays
- Revenue contribution was concentrated among major states
- Certain regions experienced longer delivery durations
- ABC analysis identified high-value inventory segments
- XYZ analysis highlighted products with unstable demand patterns

## Conclusion

This project demonstrates the application of Power BI in supply chain and logistics analytics. The dashboard transforms raw ecommerce operational data into actionable insights through KPI monitoring, inventory classification, and interactive visualizations.
